# GANIT-NM

**GANIT-NM (GANIT — Numerical Methods)** is a numerical mathematics project focused on making mathematical computation, experimentation, and visualization easier and more interactive.

## Why GANIT-NM?

Students and teachers often need to perform mathematical calculations during learning, practice, or experimentation. Some problems can involve repetitive calculations, approximations, or multiple methods, making manual evaluation time-consuming.

GANIT-NM aims to provide an interactive environment that can help with mathematical computation and experimentation.

### For Teachers

GANIT-NM can help teachers:

* Demonstrate mathematical concepts.
* Quickly evaluate and verify calculations.
* Experiment with different values and methods.
* Use visualizations to support explanations.

### For Students

GANIT-NM can help students:

* Evaluate mathematical problems.
* Verify manually calculated results.
* Experiment with different values and approaches.
* Understand mathematical behavior through computation and visualization.

## Project Vision

GANIT-NM is being developed as a flexible platform for numerical mathematics.

The project will evolve over time as new ideas, methods, and capabilities are explored. Its scope is not limited to the features currently implemented, allowing the project to grow according to future requirements and experimentation.

## Current Status

**Project initialization.**

The initial project structure and development workflow have been established. Development of the mathematical functionality is yet to begin.

## Technologies

The project currently uses a combination of **C++ and Python**, along with supporting tools and libraries for development and visualization.
